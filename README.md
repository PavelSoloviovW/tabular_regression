# Tabular Regression — RMSE Challenge

Predict a continuous `target` from 53 anonymized features. Metric: **RMSE**.

## Key insight

The target is generated by a closed-form expression:

```
target = feature_6 ** 2 + feature_7
```

This yields RMSE ≈ `1e-14` (floating-point precision), vs. a `Mean`-baseline RMSE of `~28.90`.

## How it works

`train.py` tries strategies in order and fits the first one that reports itself suitable:

| Strategy | Description |
| --- | --- |
| `FormulaModel` | Predicts `feature_6**2 + feature_7`. Suitable if RMSE against `target` < threshold. Nothing to train. |
| `MLModel` | LightGBM fallback on all numeric features with median imputation. |

All strategies implement a common `BaseModel` interface: `is_suitable(df)`, `fit(df)`, `predict(df)`.

## Results (5-fold CV RMSE)

| Model | RMSE |
| --- | --- |
| Mean baseline | `28.87` |
| Linear / Ridge / Lasso | `~28.88` |
| LightGBM (all features) | `0.0169` |
| LightGBM (`6, 7` only) | `0.0152` |
| **Poly2 + LinearRegression** | **`1.6e-14`** |
| **Formula `f6² + f7`** | **`~1e-14`** |

## EDA summary

- **Signal location:** Only features `6` and `7` matter; the rest (including `0–5, 9–12, 13–52`) are uniform noise.
- **Noise features:** All correlations with `target` are `|r| < 0.02`. Lasso zeroes out 39 / 53 coefficients.
- **Non-linear signal:** Linear models match the baseline; LightGBM/XGBoost drop RMSE below `0.02`.
- **Formula discovery:** `feature_6` vs. `target` is a perfect parabola. `PolynomialFeatures(2)` on `[f6, f7]` recovers coefficients `[0, 1, 1, 0, 0]` and `intercept ≈ 0`.
- **Distribution match:** KS-test confirms train/test distributions of `f6` (`p=0.65`) and `f7` (`p=0.04`, statistic `0.015`) are consistent.

## Design notes

- `FormulaModel` is the primary strategy — exact, deterministic, trivially interpretable.
- `MLModel` (LightGBM) is a fallback so `train.py` still yields a usable model if the input drifts from the discovered dependency.
- The EDA notebook additionally saves a full `sklearn` Pipeline (`Poly2 + LinearRegression`) to `models/eda_model.pkl`; it's a drop-in replacement for `FormulaModel` in `predict.py`.
